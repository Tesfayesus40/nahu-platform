Guiding Vision:  
Build and validate the Coffee Marketplace first, then evolve the same platform into Nahu Farms, a configurable multi-product agricultural marketplace.

## Phase 0 – Foundation (Completed)

- Architecture, Identity, Marketplace, Orders, Payments (stub), Fulfilment, Courier, Admin, Operations, CI/CD, Staging, RC1, Staging validation.

## Phase 1 – RC1 Pilot & UAT (Current)

- UAT documents, Pilot guide, Bug reporting, Release readiness, APK distribution, Pilot execution, Go/No-Go  
- No new features.

## Phase 2 – Coffee Marketplace Production (v1.0.0)

- Production deployment, Monitoring, Backups, Security, Publish apps, Release notes, Operations documentation

## Phase 3 – Stabilization (v1.0.x)

Maintenance only: Bug fixes, UX improvements, Performance, Security patches

## Phase 4 – Coffee Marketplace Enhancement (v1.1)

- Telebirr/Chapa/SantimPay, Real escrow, Notifications, Better search, Ratings, Analytics, Courier improvements

## Phase 5 – Nahu Farms (v2.0)

Extend the platform to:  
Coffee, Honey, Cereals, Pulses, Oilseeds, Fruits, Vegetables, Dairy, Poultry, Livestock, Fish, Flowers, Seeds, Fertilizer, Machinery.

## Development Principles

1. Finish one milestone before the next.  
2. No new features during validation.  
3. Keep the platform generic and reusable.  
4. Coffee is the reference implementation.  
5. Avoid duplicated business logic.  
6. Maintain PROJECT_ROADMAP.md as a living roadmap.
