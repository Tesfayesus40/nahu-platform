## 5. Security review

| Area | Finding | Severity |
|------|---------|----------|
| Catalog Admin permissions | `catalog.read` / `catalog.write`; writes also flag-gated | **OK** |
| Seller isolation | Listing/order updates scoped by `farmerId` | **OK** |
| Buyer isolation | Orders by `buyerId`; confirm-payment ownership check | **OK** |
| Courier isolation | Execution requires active assignment | **OK** |
| Admin RBAC | Role-permission seeds for moderation, delivery, disputes | **OK** |
| Pricing writes via `admin.system.config.*` | Broader than catalog-only — acceptable short-term | **Low** |
| No SellerParty yet | All sellers are farmers in schema | **Accepted** (D2 deferred) |
| Feature flag bypass | Missing flag row defaults to allow writes | **Low** — document ops must seed flags |

**Weaknesses to track (not G3 blockers):**

- S1: Prefer fail-closed if `catalog.admin.write.enabled` row missing.  
- S2: Split `pricing.admin.write` from generic system config (clarity).  
- S3: Audit log coverage for catalog mutations (verify in ops if incomplete).
